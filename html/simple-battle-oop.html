C# 학습 예제 · 기존 Unity 게임과 별도 · 2026.10.08

객체는 서로 다르게 공격하고,
전투 시스템은 같은 방법으로 호출합니다.

검사·마법사·슬라임은 하나의 부모를 상속합니다. Main은 사용할 객체를 선택하고, 전투 시스템은 그 객체의 가상함수를 호출합니다.

개발 설명 MD · Main 코드

1. 공통 기능을 부모에 둡니다

이름·체력·피격은 물려받고, 공격 피해만 각자 바꿉니다. HP는 외부에서 직접 수정할 수 없습니다.

public abstract class Character
{
    public virtual int GetAttackDamage() => 5;
    // 이름·HP·피격 처리도 이곳에 둡니다.
}

public sealed class Warrior : Character
{
    public Warrior(string name) : base(name, 50) { }
    public override int GetAttackDamage() => 12;
}

위 코드는 설명용 일부입니다. 실행 가능한 전체 코드는 Examples/SimpleBattle 폴더에 있습니다.

2. 역할을 세 곳으로 나눕니다

역할담당하는 일
데이터와 행동Character와 자식들HP 보관, 피격 처리, 공격 피해 결정
전투 진행BattleSystem턴 순서, 공격 실행, 살아 있는 적의 반격, 승패
선택과 연결Main실제 캐릭터 생성, 출력 함수 연결, 전투 시작

전투 시스템에는 “검사면 12, 마법사면 18”이라는 종류별 분기가 없습니다. 각 객체에 공격 피해를 물어봅니다.

3. Main에서 실제 대상을 넣습니다

Character player = new Warrior("검사");
Character enemy = new Slime("슬라임");

var battle = new BattleSystem(Console.WriteLine);
battle.Fight(player, enemy);

마법사를 쓰고 싶다면 new Warrior("검사")를 new Mage("마법사")로 바꿉니다. 전투 시스템은 그대로 사용합니다. 실제 예제는 실행 인수 mage로 선택합니다.

4. 이것이 다형성입니다

// BattleSystem 안의 동일한 코드
int damage = attacker.GetAttackDamage();
int applied = target.TakeDamage(damage);

virtual

부모가 기본 행동을 제공하고 자식이 바꿀 수 있도록 허용합니다.

override

자식이 부모의 가상함수를 자신의 행동으로 재정의합니다.

5. 실행해 보기

C:\Unity\1에서 다음 명령을 실행합니다. .NET SDK가 필요하며 Unity 씬 실행은 필요하지 않습니다.

dotnet run --project Examples/SimpleBattle/SimpleBattle.csproj

dotnet run --project Examples/SimpleBattle/SimpleBattle.csproj -- mage

플레이어가 먼저 공격하고 적이 살아 있으면 반격합니다. 어느 한쪽의 HP가 0이면 종료합니다.

새 궁수도 Character를 상속하고 GetAttackDamage를 재정의한 뒤 Main에서 선택하면 됩니다. 움직임·확률·무기 교체 등은 이 작은 예제에 아직 넣지 않았습니다.
