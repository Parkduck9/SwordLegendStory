4. 알려진 문제·한계

  • R1~R8 직접 조작 미확인 — 합 공격 입력 시간, 턴 교대 리듬, 난이도는 시험값.
  • 적 공격 동작 중 검 방향은 쥔 손 방향 추정이라 일부 동작에서 어색할 수 있음.
  • 플레이어 베기는 IK 궤적 + 기본 동작(KayKit 동작으로 바꿀 여지).
  • KayKit은 다른 체형용 재타깃 — 손·발 위치 약간 어긋날 수 있음.
  • 적 손목 끝동이 일부 자세에서 비스듬한 판처럼 보임 · 무료 남자 모델은 근육질 체형 하나.
  • Windows 빌드 미작성 · 미사용 파일 T_Hair_2_* 정리 후보.
